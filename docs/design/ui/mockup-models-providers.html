Defaults & fallback

What runs when a thread or agent doesn't name its own model, and what happens when that model can't run.

Used by agents created from now on, and by new threads. Your 5 existing agents keep the model they were created with — change those on the agent. Open threads that never named a model switch on their next turn.

When the default can't run

Because the allowance is spent, the sign-in has expired, or the model isn't available. Agents with their own fallback use that instead — this covers everything else.

1 gpt-5.6-lunaOpenAI · Codex CLI · your ChatGPT plan
2 claude-sonnet-5Anthropic · Claude Code CLI · same allowance as the default
⚠ claude-sonnet-5 shares the Claude Code CLI allowance with your default. If the default stops because that allowance is spent, this backup will be unavailable too.
In plain terms: anything that doesn't name its own model runs claude-opus-5 through your Claude subscription. If that can't run, Polyphemus tries gpt-5.6-luna on your ChatGPT plan, then claude-sonnet-5, and tells you which one it used. It will never switch to a per-token API way in.
