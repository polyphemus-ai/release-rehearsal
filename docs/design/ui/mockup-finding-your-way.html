B · One direction, at 1200px: arrange the list, stay in a project

A View control on Home groups the same list by time, project or agent. Here it’s grouped by project. Opening a project from a group, or from Projects, puts a project chip on the list, so Home stays filtered to it until you clear it. The thread pane says where you are and gets you to the project’s setup in one tap.
