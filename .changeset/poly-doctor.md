`poly doctor` says what this computer has and lacks for Polyphemus — Node and git, the Claude Code,
Codex and Grok Build CLIs and whether they're signed in, Codex's sandbox, Docker or Podman against
where agents are set to run, Tailscale and its HTTPS address, paired phones, a browser — and what to
do about each gap. It changes nothing. With `--json` (or when piped) it answers an agent, and it
exits 1 when something stops Polyphemus doing its job.
