A connection can be granted to an agent, not only to a project. The agent carries it wherever it works — a direct thread with it included, where connections could reach nothing before — and on top of what each project it works in grants. Grant it from the connection ("Grant to an agent") or from the agent ("Give it a connection of its own"); what a credential can do still bounds it, and an agent's grant inside a project still only narrows that project's.
