The model list names only agents you can see, and counts only threads you can see. An archived count is yours too, worked out without reading every old thread. A service refusing one action leaves the connection up; a bad sign-in still asks you to fix it. Saying yes to bringing an agent in while a thread is working still starts them when that turn ends. Someone who can only read a thread sees why the agents paused. Codex keeps a connections token in a file only you can read, not on its command line. A device whose person is gone is signed out, instead of acting as the owner.
