An agent can propose a change to its own profile — who it is, what it does here, its one-line description — which shows under Waiting on you with the new text beside what it says now. Accepting rewrites the profile; nothing changes until then. Before, an agent had to leave draft files on the computer running Polyphemus and ask a person to copy them in.
