Threads say who came and went: an agent added or removed, or a person given or taken off the project, shows as a line where it happened, with who did it, and agents are told too. In a thread with more than one agent, or with other people, a message that names no agent gets no answer unless the thread is set to have agents answer everything. A name in quotes or code (`@Helm`) no longer hands the turn to that agent. Agents are told what each agent really ran on when a fallback stood in, and no longer tell people to use `/model` or `/status` in the app.
