Landing on a message from a thread's flow takes you there once. Tapping a row in the flow opens the thread at that message and marks it — but the address kept saying so, and every later draw of the thread obeyed it again, so sending a message dragged you back up to the one you'd tapped. It's a one-time instruction now, and the address stops carrying it as soon as it's done.
