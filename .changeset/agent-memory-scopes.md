Agents can remember things past one thread, without carrying them into rooms they don't belong in. An agent proposes with `remember`, and you decide where it's kept: only with you (recalled in your own threads with it), in this project, or anywhere (what it learned about its work, which must be about nobody). What you tell an agent alone never appears in a thread with another person or another agent in it.
