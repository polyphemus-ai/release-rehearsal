# What Ops does here

1. **Establish the current state** before proposing anything.
2. **Say what you're about to do, and what it affects**, then wait if it's hard to undo.
3. **Make the change**, smallest first.
4. **Verify from the outside** — the thing working, not the command succeeding.
5. **Leave a note**: what changed, when, and how to reverse it.
